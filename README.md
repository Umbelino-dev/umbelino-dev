# Umbelino Dev — Portfólio

Site pessoal / portfólio construído com React, TanStack Start e Tailwind CSS.

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19 + SSR)
- [TanStack Router](https://tanstack.com/router)
- Tailwind CSS v4
- Componentes Radix UI
- Build com Vite + Nitro

## Desenvolvimento local

Requer Node.js 20+.

```sh
npm install
npm run dev
```

O site sobe em `http://localhost:8080`.

## Build

```sh
npm run build
```

## Deploy

O projeto está configurado para build automático na [Vercel](https://vercel.com), com deploy disparado a cada push na branch `main`.
